CCTV MONITOR P0.12 — SECURITY, SESSIONS & AUDIT

UPGRADE FROM P0.11.2
1. Stop CCTV Monitor with Ctrl+C.
2. Back up the working P0.11.2 folder.
3. Extract the P0.12 upgrade patch over the working folder.
4. Keep .env, data\, data\.credential-key, node_modules\ and package-lock.json.
5. Run: npm install --package-lock-only --ignore-scripts --no-audit
6. Run: npm run check
7. Run: npm run test
8. Run: npm run build
9. Run: .\START-CCTV-MONITOR.cmd
10. Run: .\QUALIFY-P0.12.cmd

IMPORTANT
- Do not run `npm audit fix --force` as part of this upgrade.
- Existing account passwords remain valid; new/changed passwords require at least 12 characters.
- New Viewer accounts default to AI disabled.
- Revoking a session blocks future API/media authorization. An already-established WebRTC connection can persist until disconnected.
