CCTV MONITOR P0.14.1 COMPLETE BUILD MANIFEST
============================================

Application version: 0.2.0-p0.14.1-pw8
Database schema: v8
Release focus: Motion Snapshots, Rectangular Zones & Event Review

Core additions
--------------
- motion_zones persistence and CRUD
- maximum 4 rectangular zones per USB camera
- per-zone enable/disable and optional sensitivity override
- whole-frame compatibility mode when no zones exist
- separate low-rate MediaMTX analyzer per enabled zone
- one-frame authenticated JPEG snapshot per motion event when capture succeeds
- visible zone rectangle overlay on snapshots
- motion event context endpoint
- review states: unreviewed / confirmed / dismissed
- optional reviewer note
- historical zone name retained after zone deletion
- P0.14 linked recording behavior retained

--------------------
- tools/mediamtx/mediamtx.yml
- src/server/services/FfmpegService.ts
