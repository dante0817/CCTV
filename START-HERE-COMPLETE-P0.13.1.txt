CCTV MONITOR P0.13.1 — COMPLETE FRESH-INSTALL PACKAGE
======================================================

P0.13.1 includes the complete P0.13 PW8 application plus Recording Management, Storage & Safe Retention.

FRESH INSTALL
1. Extract this ZIP to a new folder.
2. Open PowerShell in that folder.
3. Run:
     .\FIRST-RUN-P0.13.1.cmd
4. Open http://localhost:3000 if the browser does not open automatically.

REUSE AN EXISTING INSTALLATION
You may copy these from a verified prior P0.13/P0.12 installation before first startup:
- .env
- data\
- data\.credential-key
- package-lock.json (only if it matches the same dependency set)
Do not copy node_modules; install dependencies fresh.

PASSWORD POLICY
New or changed passwords are 5–8 characters. Existing migrated passwords continue to authenticate until changed.

RECORDING / RETENTION
- USB continuous recording remains the qualified recording source.
- Retention is DISABLED by default.
- Protected recordings cannot be deleted by retention or manual delete.
- The active segment, quarantined leftovers and unknown files are never retention candidates.
- Retention settings live in Recordings → Safe Retention Policy.

VERIFY
  .\VERIFY-P0.13.1-COMPLETE.cmd

HARDWARE QUALIFICATION
  .\QUALIFY-P0.13.1.cmd

Normal startup after installation:
  .\START-CCTV-MONITOR.cmd
