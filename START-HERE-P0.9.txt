CCTV MONITOR P0.9 — DEPLOYMENT & RELIABILITY

1. Copy your working P0.8.4 data\ folder and .env into this P0.9 folder.
2. Run START-CCTV-MONITOR-PRODUCTION.cmd once.
   - It installs missing Node packages if necessary.
   - It installs MediaMTX if missing.
   - It builds the production frontend/server.
   - It starts the production runtime.
3. Confirm local Live View and the existing Tailscale Serve remote URL still work.
4. In the Tailscale Windows client, enable Run unattended for this CCTV PC.
5. Run INSTALL-AUTOSTART.cmd to install the conservative at-sign-in Scheduled Task.
6. Run QUALIFY-P0.9.cmd and complete the manual gates shown there.
7. After Serve/reboot tests pass, you may run REMOVE-DIRECT-TAILSCALE-WEB-RULE.cmd as Administrator to remove the temporary direct :3000 tailnet firewall exception.

Do NOT enable Tailscale Funnel or router port forwarding.
Do NOT use the experimental SYSTEM-at-startup task until the USB webcam has been qualified in that noninteractive startup context.
