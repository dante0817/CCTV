CCTV MONITOR P0.14.1 - COMPLETE STANDALONE BUILD
=================================================

Purpose
-------
P0.14.1 adds motion snapshots, rectangular motion zones, and motion-event review on top of P0.14 motion detection and P0.13.1 recording management.

Fresh install
-------------
1. Extract this ZIP into a new folder.
2. Open PowerShell or Command Prompt in that folder.
3. Run:

   FIRST-RUN-P0.14.1.cmd

4. After first-run validation, normal startup is:

   START-CCTV-MONITOR.cmd

5. Browse to:

   http://localhost:3000

Existing data
-------------
To carry forward an existing installation, first stop CCTV Monitor and back up the old folder. Copy only the persistent configuration/data you need, especially:

  .env
  data\
  data\.credential-key
  package-lock.json   (when it matches this package's dependency pins after npm refresh)

Do not copy an old node_modules folder into a clean install.

P0.14.1 qualification
---------------------
Run:

  VERIFY-P0.14.1-COMPLETE.cmd
  QUALIFY-P0.14.1.cmd

Important defaults
------------------
- Motion detection remains OFF until explicitly enabled.
- If no motion zones exist, the whole frame is analyzed.
- Once zones exist, only enabled zones are analyzed.
- Up to 4 rectangular zones are supported per USB camera.
- Snapshots are stored under data\snapshots by default and served only through authenticated routes.
- Motion-event review status is separate from ordinary Event acknowledgement.
- New/changed passwords remain 5-8 characters as requested.

Protected media path
--------------------
The known-good MediaMTX config, USB FFmpeg capture service and browser CameraPlayer remain protected by BASELINE-P0.14.1.sha256.
