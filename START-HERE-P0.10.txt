CCTV MONITOR P0.10 — ROLE-BASED ACCESS

UPGRADE FROM P0.9
1. Keep your existing .env file and data\ folder. The database migration runs automatically.
2. Replace the application files with this P0.10 folder (or copy .env and data\ into it).
3. Double-click START-CCTV-MONITOR.cmd for development, or START-CCTV-MONITOR-PRODUCTION.cmd for the production launcher.
4. Sign in as Administrator.
5. Open Users and confirm accounts. Legacy Operator accounts will now be Viewer accounts.
6. Open Camera Access and verify Live View / Recordings assignments for every Viewer.
7. Test Viewer login from the tablet: it should land directly on Live View and show only assigned cameras.
8. Run QUALIFY-P0.10.cmd and complete every manual release gate.

IMPORTANT
- Do not delete data\cctv.db during an upgrade.
- New Viewer accounts receive no cameras until assigned by Admin.
- Admin accounts always have all-camera access.
- 0.0.0.0:3000 is a bind address, not a browser URL. Use http://localhost:3000 locally or the printed LAN/VPN URL.
